Learn how to build automated email alerts for blocking chains and long-running queries on Amazon RDS for SQL Server. This serverless solution uses AWS Lambda, Amazon CloudWatch, and Amazon SES to detect blocking, identify the root blocker, and send HTML email alerts for approximately $2.57 per month.
