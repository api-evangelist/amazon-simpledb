Migrating SQL Server Integration Services (SSIS) packages is one of the more complex parts of moving from SQL Server to Amazon Aurora PostgreSQL. In Part 1 of this two-part series, learn how to filter, categorize, and simplify your SSIS portfolio using native PostgreSQL features, pg_cron, and the aws_s3 and aws_lambda extensions.
