Learn how to use AWS DMS and a Db2 gateway server on Amazon EC2 to migrate and replicate data from an on-premises IBM Db2 database on z/OS to Amazon Aurora PostgreSQL. This post covers configuring the gateway, creating DMS resources, running a full load with periodic full-load refresh, and validating the migration.
